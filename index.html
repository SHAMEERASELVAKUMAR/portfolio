From a line of code to a live app.

Here is what happens each time something new goes out. Scroll and watch it light up.

A developer pushes code.

It lands in GitLab on a dev or prod branch, and that branch decides where it goes.

Jenkins builds it.

A pipeline picks it up, uses a build agent and the right credentials, and builds the frontend and backend.

Docker packages it.

The app runs in a container, so it behaves the same on AWS, Oracle Cloud or a server in the office.

Nginx puts it online.

The domain points to the right service, and an SSL certificate keeps every visit secure.

Monitoring keeps watch.

Prometheus, Grafana, Blackbox Exporter and cAdvisor show CPU, memory, disk, containers and website uptime, so I see trouble before users do.

Phone apps follow the same path: iOS builds run through Jenkins, then go to the App Store and Google Play.
